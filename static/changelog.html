v6.306 雲端牌組不再每次整批重新下載
已登入帳號進入對戰頁或牌組頁時，牌組沒變動就不再整批重新下載，進頁更快。⚠ 首次進站、換裝置或牌組有改動時仍會完整同步一次；需等伺服器設定更新後生效。
已登入帳號（Google 等）的雲端牌組，先前每次進入對戰頁或牌組頁都會把所有牌組整批重新下載一次，牌組越多進頁越慢，手機上尤其明顯。這一版起會先確認雲端牌組有沒有變動：沒有變動就直接沿用本機已有的牌組，不再整批下載。⚠ 第一次進站、換裝置、換帳號、或在別的裝置改過牌組時，仍會完整同步一次，之後才開始省。⚠ 匿名（未登入）使用者本來就不使用雲端牌組，不受影響。⚠ 需等伺服器設定更新後才會生效，更新前維持先前的行為。
v6.305 指定隻數的多目標招式現在必須選滿
酋雷姆「三重冰霜」、鐵頭殼ex「雙刃劍」等卡面寫「對手的 N 隻寶可夢各受到傷害」的招式，選擇目標時必須選滿指定隻數；對手場上不足時則全部選取，不能只選一部分。
卡面寫「對手的3隻寶可夢各受到110點傷害」這類指定隻數、而且沒有「最多」二字的招式屬於強制效果：對手場上有 3 隻以上時必須剛好選 3 隻，只有 2 隻時就必須選那 2 隻。先前酋雷姆「三重冰霜」與鐵頭殼ex「雙刃劍」只選 1 隻也能確定，這一版起與其他同類招式（雙尾怪手「雙尾」、電擊魔獸ex「二重伏特」、三首惡龍ex「黑曜石」、火箭隊的叉字蝠ex 的特性「亂咬」等）一致，都必須選滿。⚠ 卡面寫「最多 N 隻」的效果（玻璃喇叭、阿杏的秘招、火箭隊的尼多娜「惡之覺醒」）維持可以少選。
