# 後台工作介面（v6.630）

這版只整理管理端的導覽與資料閱讀方式；權限、API、查詢上限、賽事與遊戲行為維持既有實作。公開網站不載入這套介面，也不列出管理操作更新。

## 導覽

- 桌機左側顯示全部 16 項功能，依日常管理、賽事與牌組、統計與紀錄、系統設定分組。
- 900px 以下改成完整功能抽屜，底部常駐對戰、賽事、玩家、監控、全部入口。重新整理留在頁首；強制更新及登出可從完整功能選單操作。
- 功能尋找按搜尋或 Enter 後才篩選入口，只搜尋本機標籤與別名，不打 API。
- 頁首顯示目前分頁與「跳至」區段選單；跳轉會展開所需區塊與原生 details，並提供回頁首入口。

## 長頁與資料列表

- 手機將同一容器內的主要閱讀區段收合，保留原 DOM、輸入值與既有事件。桌機仍展開全部區段。卡包政策的共用儲存、清除及結果訊息留在區段外。
- 一般單層表頭、各列欄位一致的表格提供手機摘要卡片與完整表格選擇。識別欄及常用唯讀入口直接呈現，其餘資料和管理操作可展開；矩陣、熱圖及複雜跨欄表格保留原表格。
- 摘要卡片先顯示目前資料頁的 10 筆，可再顯示 10 筆或顯示本頁全部；這是本機顯示限制，不改伺服器原本每頁 50 筆的分頁與排序。
- 完整表格保留所有欄位與資料列，可左右捲動；桌機沿用完整表格。排序選單呼叫原表頭事件，不另寫第二套排序判準。
- 後台完整更新紀錄每頁 20 則、預設牌組管理清單每頁 10 則，均在本機翻頁。搜尋仍針對原完整資料，不限目前顯示頁；不會清掉尚未提交的匯入文字。
- 表格顯示方式只以 `ptcg_admin_ui_table_<分頁>` 儲存 cards/table 偏好，不儲存玩家資料或未提交設定。儲存空間不可用時仍能操作。

## 彈出視窗與手機

- 管理明細提供固定在視窗內容頂端的關閉／返回按鈕，轉呼叫原有按鈕，保留一般視窗堆疊與賽程視窗的不同關閉語意。
- 堆疊返回後重新綁定關閉事件；只有最上層可取得焦點，Tab 留在該層，Escape 呼叫其原有關閉動作。全部關閉後還原背景捲動與仍存在的原入口焦點。
- 手機輸入框使用 16px 字體，主要操作有足夠點擊高度；統計卡片雙欄、圖表單欄，彈窗限制在可視高度內捲動，並保留頂底安全區。
- 房間列表上下跳頁輸入框各自有唯一 ID，底部 Enter／跳頁按鈕讀取底部自己的數值。

## 維護與驗證

`oracle-admin/admin.html` 的 `v6630-admin-workspace` 區塊是管理端閱讀層，移動既有分頁 DOM 並觀察目前分頁更新；`switchTab` 僅通知介面狀態，原 loader 仍是唯一資料入口。這層不新增 API、輪詢或後端異動。

`scripts/test-v6630-admin-workspace.mjs` 透過 `scripts/lib/admin-workspace-fixture.mjs` 執行完整真 HTML／模組，僅替身外部 SDK、驗證及 API 資料。測試不得連線或寫入正式服務。`scripts/mutcheck-v6630-admin-workspace.mjs` 只改獨立暫存副本，驗證守衛能攔截實際回歸。

瀏覽器自動化的手機尺寸檢查不等同原生 iPhone 實機驗證。部署仍由站長執行；後台檔案須經 `update-tournament.bat` 更新，GitHub Pages 不提供 admin 頁面。
