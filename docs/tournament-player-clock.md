# 錦標賽個人操作時間

功能預設關閉。站長可在admin「監控」的「錦標賽個人操作時間」設定開關與每人每場額度；初始15分鐘，可輸入1～120整數分鐘。關閉即沿用原本對戰方式；整場時限、最後回合判定與閒置規則仍有效。

啟用時，只計玩家實際需要操作的時間，等待對手選牌／補位不扣本人時間。引擎允許雙方各自處理必要待辦時，兩人各計自己的時間。開局準備不扣個人額度。每場重新計算，重新整理／斷線不重置。

個人額度用完，當下給30秒收尾，此後每半回合使用共用30秒操作額度；出牌或連續選擇不重置。非本人回合仍需做選擇時，必要操作也有該半回合的共用額度。等待對手暫停、交還操作權後續倒數。

歸零後，伺服器只完成必要選擇、已發動效果的代價、取獎賞、補位，並沿原引擎結束回合；不替對手選擇，不主動開始新出牌或攻擊。若電腦無法合法推進，保留盤面與真人操作供恢復，不刪選擇或跳過卡牌效果。

桌機與手機均有可拖曳提醒浮窗，逐秒倒數，最後10秒改高對比。沒有遮罩或確認步驟，浮窗內容不阻擋底下操作，標題可拖曳移開。

## 管理中途調整

- 開啟：新對局與進行中的對局開始計時，舊局不追溯啟用前耗時。
- 調高／調低：保留已用時間；調低導致額度已耗完時先給完整30秒，不立即操作。
- 關閉：取消尚未開始的接管；已開始的原子寫入會在回覆成功前完成，已完成動作不倒退。
- 再開啟：從此次啟用重新計算額度。

伺服器設定／資料庫暫時不可讀時會停止強制處理，保留已存時間與操作責任。admin讀取失敗顯示狀態未知。

## 發布

需要先由站長在無賽事時執行`update-tournament.bat`，再執行`redeploy-oracle.bat`。第一支包含新版伺服器引擎、補丁與admin，第二支發布玩家介面。AI不代跑。GitHub Pages測試站不能代表Oracle新後端已部署，必須確認admin v1.89／玩家v6.592，且初次設定仍關閉。
