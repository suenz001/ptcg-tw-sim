# 待站長逐張複核：「最多N張」的已知資訊 picker 可否選 0

> **背景**：站規是「已知資訊（棄牌區／自己手牌／自己場上）預設必選至少 1」，
> 只有卡面寫「任意數量／若希望／以任意方式／任意選擇」才放行。
> 下列 23 張卡面是**純「最多N張」**（沒有上述字樣），目前一律**必選至少 1 張**。
>
> **v6.126 查到的官方判準可以參考**：官方對「可否選 0」的分界是
> **搜尋對象帶不帶條件**、以及**該區是不是公開資訊**——
> ・牌庫（非公開）+ 帶條件 → 可宣告「找不到」而選 0
> ・牌庫（非公開）+ 無條件「任意選擇」 → 官方明文**必須選 ≥1**（L1454/L1708/L2333/L1373）
> ・**棄牌區／自己手牌／自己場上是公開／已知的**，沒有「找不到」可宣告 → 官方沒有對應判例
>
> 所以下面這 23 張**官方規則沒有直接答案**，是站規問題，由你決定。

**怎麼回覆**：在每張的「判定」欄填 **可選0** 或 **必選**（不填＝維持現狀必選）即可，
也可以只告訴我「哪幾張要改成可選0」，其餘我維持不動。
