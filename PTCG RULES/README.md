## 使用順序與界線

1. 先遵守專案 `IRON_RULES.md`、站長已確認的裁定及 `_handoff/skills/ptcg-rulings-first/SKILL.md`。本入口沒有變更這些政策。
2. 通則與流程查有版本的官方 PDF；卡牌互動查台灣官方直接 Q&A，並核對卡面。摘要與人工速查不能凌駕官方原文。若官方資料之間有疑義，應核對日期、適用範圍及直接判例，不自行發明優先順序或改行為；推翻站長裁定前須先回報。
3. 卡牌事實仍以 `static/cards` 對應的台灣官方繁中卡圖為準；歷史參考卡文字、官網 detail 的欄位不能直接匯入遊戲。本站仍只維護 H／I／J 標。
4. 賽場規則及裁判罰則包含實體賽事運營事項；不能直接把它們轉成本站自動判負、計時、封鎖或錦標賽政策。
5. 修改行為前須建立「官方依據 → 實際情境 → applyAction 完整流程 → 正反對照」的對照與測試。下載文件與文字搜尋本身不能證明引擎正確。

## 既有文件的狀態

- `PTCG_RULES.md`／`PTCG_RULES.json` 是站內整理；Q&A 收錄基準為 2026-04-28。保留原行號，避免歷史引用失準；查不到時仍須查最新官網。
- `PTCG_QUICK_LOOKUP.md`、`AGENT_PROMPT.md` 與原有 3.4 PDF 保留作歷史參考。**前兩份尚有舊敘述，不可直接當作現行規則或本次工作指令**；例如速查表「先攻首回合不抽」、同名競技場替換條件，與已校正主檔／官方線上教學不符。這次沒有宣稱逐條校正所有舊摘要。
- `scripts/data/official-qa.json` 是既有判例快照，非本次全量重新下載；是否完整須看該檔查詢資訊。官網列表翻頁會重疊，不能以抓完頁數就宣稱已取得全部判例。
- 紙本系列遊戲說明書與線上教學是不同資料；未找到可驗證的官方公開下載原檔時，必須標記待補，不能把其他手冊改名冒充。

## 更新方式

以新日期資料夾新增官方原檔，記錄下載入口、實際檔案 URL、版本、官網更新日、PDF 內文日期、下載時間、頁數及 SHA-256；保留舊版。確認原檔是 PDF 而非錯誤 HTML，並比對文字擷取與實際渲染。維護資料放在 `PTCG RULES`，不要放進 `static`、前端 import、API 或伺服器輪詢。
