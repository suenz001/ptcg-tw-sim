## PDF 與文字

原始 PDF 依官網實際附件路徑下載，未重新編輯、壓縮或補字；記錄 HTTP 狀態、內容類型、大小、SHA-256、來源入口與下載時間。PDF 頁數以 pypdf、PyMuPDF 兩套解析器交叉確認，並逐頁渲染確認可以開啟；代表頁的圖片另存本機供人工檢視。

衍生的文字／Markdown 統一 LF 換行並移除行尾 ASCII 空白；JSON 只統一檔案換行，不改欄位內容。原始官方 PDF、來源 HTML 與卡牌擷取快取維持原樣。初次加入 Git 時發現 Windows 自動換行轉換及擷取文字的行尾空白，故補上僅此封存資料夾適用的 `.gitattributes`，更新衍生檔案雜湊後重新驗證；不放寬檢查。

現有 49 份卡表不屬於這個新封存資料夾，其原本 Windows 工作樹為 CRLF、Git blob 為 LF；本次不改卡表或專案全域 attributes。coverage 分別記錄當時工作樹 `sha256` 與指定基準的 `gitBlobSha256`／`gitBlobSource`，並逐份確認解析後 JSON 相同，避免未來在 Linux 或另一台電腦把純換行差異誤判為卡牌內容被改動。

部分官方 PDF 的 xref 存在無效物件參照，pypdf 會顯示忽略物件警告；兩套解析器頁數一致、頁面可渲染且原始下載位元組未修改。本次未據此重寫官方 PDF。3.4.1 字形異常、罰則 PDF 空白頁、賽場規則封面目錄頁碼與實際 PDF 頁碼差異，都明確保留與揭示。

這些檢查證明下載與資料索引的完整性，不能證明規則摘要、卡牌欄位或對戰引擎已逐條符合官方規則。
